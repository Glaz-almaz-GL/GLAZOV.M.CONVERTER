# GLAZOV.M.CONVERTER

Библиотека .NET для конвертации файлов между форматами (документы, изображения, аудио, видео) и простых преобразований изображений — для файлов на диске и для потоков (`Stream`). Тип входного файла подтверждается по начальным байтам до конвертации.

Проект только заведён; код не написан.
